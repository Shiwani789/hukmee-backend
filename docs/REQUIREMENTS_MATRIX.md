## Existing files to preserve

Preserve `prisma/schema.prisma`, `prisma/migrations/20261016110000_init/migration.sql`, migration lock, tests, README, and existing lower-case docs. Any schema change requires reference/data-impact review and a forward migration; do not delete existing fields/models based on this matrix.

## Source limitations

The canonical Express app mounts auth, catalog, devices, bookings, inventory, user profile and addresses. Additional legacy directories exist under `src/modules` (including banner, CMS, KYC, notification, payment, review and vendor), but their routes are not mounted in `src/app.ts`; several reference unavailable legacy imports/models and fail compilation. Do not count them as implemented APIs. The build and lint configuration currently excludes these unmounted legacy modules; they remain incompatible and are not verified.

The initial checkout issues and commands are recorded in [repository audit](REPOSITORY_AUDIT.md). Current implementation and validation evidence are in [Phase 1 report](phase-1-report.md). The database-backed integration test remains skipped without a dedicated migrated `*_test` database.
